# registry

The identity and server-directory service that Odyssey game servers register
with — how worlds are discovered and how identity is anchored across servers.

**In scope:** server registration and the discovery directory, cross-server
identity anchoring, the service's own authentication and data protection.

**Out of scope:** running or simulating a world (see `server`), player-facing
presentation (see `client`), operator and host-facing tooling (see
`admin-tools`), the shared protocol contract (see `proto`).

**License:** AGPL-3.0 — the registry is a world-running system of the engine;
network copyleft protects the commons for hosted software.
